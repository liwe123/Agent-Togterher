## 三、🔴 报告外新发现的真实缺陷

### 3.1 `usePermissions()` 无参调用 3 处 → 管理员权限恒失效（高危，功能性 BUG）

20260907 报告只列了 `plugins` 与 `workflows` 两处，定性为"顺手修正"。实测**有第三处，且后果最严重**：

| 文件:行号 | 调用 | 受影响功能 | 后果 |
|---|---|---|---|
| `app/settings/quota/page.tsx:28` | `usePermissions()` 无参 | `:69` 保存提前 return、`:254/272/290/308/329` 输入框 `disabled={!isAdmin}`、`:336` 保存按钮 `{isAdmin && ...}` 不渲染 | **owner/admin 也无法保存任何配额配置**（功能完全不可用） |
| `app/settings/plugins/page.tsx:31` | `usePermissions()` 无参 | `:92,315` toggle 按钮 | 插件启停对所有人不可点 |
| `app/workflows/page.tsx:36` | `usePermissions()` 无参 | `:146,161,232,355` 新建/删除按钮 | 工作流模板管理入口对所有角色隐藏 |

**根因**：`hooks/use-permissions.ts:3` 签名 `usePermissions(role: WorkspaceRole = "viewer")`，无参即 role=viewer，`isAdmin` 恒 false。正确先例：`app/settings/members/page.tsx:36` 传 `currentUserRole`。
**修复成本**：3 行改动（加 `useWorkspaces()` 取 `currentUserRole` 并传入）。
**判定建议**：属 BUG（管理员实际无法操作 = 坏行为），而非 C1/C2 的附赠项。建议独立成一个 `fix:` 提交优先处理。

### 3.2 `.gitignore` 空档 → `git add -A` 会误收 88 条路径

`backend/.pytest-temp/`（pytest 临时产物，含未被 `*.db` 覆盖的目录/symlink）与 `docs/.archify-delivery-*/`（archify 工具产物）**均未被忽略**，`git check-ignore` 判定 `rc=1`；`git add -n .` 显示会被纳入。虽守则 4 明令禁 `git add -A`，仍应补两行 `.gitignore` 消除隐患。

### 3.3 P2-3 清理清单漏项

`backend/data/smoke_p0.db`(303KB)、`backend/data/agent_console.db`(288KB) 仍在磁盘——原清理清单未覆盖 `backend/data/` 子目录。（已被 `*.db` 忽略，仅磁盘残留。）
