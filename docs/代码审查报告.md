## 三、审查发现（按严重度，未全部修复——建议后续）

> 标记 **[已复验]** 为本轮人工直接确认；**[子Agent]** 为独立探查结论，建议后续处理前再复核。

### Critical / High

1. **[已复验] 零认证默认（auth bypass）。** `app/core/security.token_required()` 在 `APP_API_TOKEN` 未设置时返回 `False`，`main.py:48-61` 的鉴权中间件整体跳过 → 所有 REST/WS 接口裸奔。docker-compose 已透传变量，但**未强制要求必须设置**，仍有误配即开放的风险。建议：未设置 token 时拒绝启动或仅允许本地回环。
2. **[已复验] 重复的 `_build_task_context_messages`（orchestrator.py:117 与 :700）。** 同名方法定义两次，类属性以 :700 为准，:117 起约 90 行成为死代码（调用点 246/357/421/509/555 均走 :700 版）。建议删除 :117 死代码。
3. **[子Agent] 并发上限竞态 + 旁路。** 活跃任务 `cap=3` 为 check-then-act，且只在 `receive_user_message` 生效，`POST /api/tasks` 可绕过 → 并发额度可被突破（DoS/资源耗尽）。
4. **[子Agent] 租约丢失不中止。** orchestrator.py:196-217 在租约过期后未主动中止任务，可能导致重复执行。
5. **[子Agent] 工作区隔离缺口（IDOR 风险）。** 部分 REST 端点未严格按 `workspace_id` 过滤（已确认 `conversations/agents/tasks/workspaces/models` 有引用，但子 Agent 指出存在特定旁路）。建议对全部读路径补充 workspace 归属校验。
6. **[子Agent] WebSocket 无 Origin 校验**（`websocket/router.py`），存在跨站 WebSocket 劫持面。
7. **[子Agent] Provider Key 明文存库**，建议信封加密或托管到密钥服务。
8. **[子Agent] 无界递归恢复**（orchestrator.py:641-649），异常链可能导致栈溢出。

### Medium

- **[子Agent] 成本提取读错字段**，成本统计失真。
- **[子Agent] `fallback_used` 未持久化**，降级观测缺失。
- **[子Agent] `model.call_finished` 两种 payload 形态**，下游解析脆弱。
- **[子Agent] 自定义模型 `configured` 仅按 env 判定**，忽略 DB 配置。
- **[已复验] 前端 `software-dock.tsx` 仍被渲染**（agent-console.tsx:81），与 README 历史描述“已移除”矛盾（README 已澄清为“保留面板”，代码与文档现已一致）。
- **[子Agent] 前端定时器泄漏**：`use-tasks.ts` / `useTaskDetail` 的 `scheduleRefresh` 未在卸载时 `clearInterval`。
- **[子Agent] `task-utils.ts shouldApplyTaskStatus`**：终态（completed/failed/cancelled）同 rank，相等时间戳会互相覆盖。
- **[子Agent] `agent-console.tsx:35` 使用 `backdrop-blur-md`** 玻璃拟态，与前端设计哲学（去玻璃化）冲突；另有多处霓虹 `shadow-[0_0_6~10px_...]` 发光，建议收敛。

### Low / 已合规（正向）

- ✅ `ErrorBoundary` 已正确挂载于 5 个页面组件。
- ✅ git 工作区干净（仅 `.workbuddy/` 未跟踪，现已 ignore）。
- ✅ PRD.md ↔ docs/prd/*.md ↔ PRD.html 三方同步。
- ✅ 变更表 14 列、表头第 2 行、冻结首行/首列、按类型配色、自动筛选均合规。
- ⚠️ 历史 10 个非 Conventional Commit 不可改写，仅作为已知项记录。
