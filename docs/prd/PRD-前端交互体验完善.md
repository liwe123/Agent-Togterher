# PRD：前端交互体验完善

> 类型：新需求（Requirement）｜状态：已实施

## 1. 背景与问题

现有 Agent Console 已具备控制台、群聊、通讯录、任务与模型设置等核心页面，但部分高频操作仍缺少完整交互闭环：软件 Dock 仅展示状态而不可查看详情，聊天消息只能按纯文本显示，移动端缺少快捷指令入口，高风险配置操作缺少统一确认与结果反馈。

## 2. 目标与非目标

**目标**
- G1：让软件 Dock 入口具备真实、键盘可达的连接详情交互。
- G2：提升 Agent 输出的结构化阅读能力，支持安全 Markdown、代码与复制操作。
- G3：为移动端聊天提供 Agent 与快捷指令选择入口。
- G4：统一高风险操作确认与保存、删除、测试结果反馈。

**非目标**
- N1：不修改后端 API、WebSocket 事件或数据库结构。
- N2：不引入复杂动画框架或富文本编辑器。
- N3：不改变现有路由及 Agent 调度流程。

## 3. 用户故事

- US1：作为运维人员，我可以点击软件 Dock 查看端口、连接状态和最近心跳，而不是点击后没有反馈。
- US2：作为开发者，我可以清晰阅读 Agent 返回的标题、列表、代码和链接，并快速复制代码或全文。
- US3：作为移动端用户，我可以通过操作面板选择 Agent 或快捷任务模板，无需记忆并手输完整名称。

## 4. 功能需求

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR1 | Software Dock 每个入口使用语义化按钮，点击后显示软件名称、接入位、连接状态与可用操作 | P0 |
| FR2 | Agent 消息支持安全 Markdown 渲染、代码块、列表与安全外链 | P1 |
| FR3 | 移动端聊天输入器提供快捷模板和 Agent 选择面板 | P1 |
| FR4 | Agent 详情弹层支持 Escape、遮罩关闭、焦点恢复和背景滚动锁定 | P0 |

## 5. 非功能需求

- 键盘可完整操作，弹层遵循 WAI-ARIA Dialog 模式。
- 移动端触控目标不小于 44px。
- Markdown 不渲染不可信原始 HTML，外链提供安全属性。
- 新能力不得破坏现有聊天发送、任务跳转和设置保存流程。
- `lint`、前端测试、生产构建与冒烟测试全部通过。

## 6. 验收标准

- AC1：Software Dock 入口可通过鼠标、Enter 和 Space 展开或收起连接详情。
- AC2：Agent Markdown 中的标题、列表、行内代码、代码块和链接显示正确，原始 HTML 不执行。
- AC3：375px 宽度下可从输入区打开快捷操作并选择模板或 Agent。
- AC4：Agent 详情可用 Escape 和遮罩关闭，打开时背景不可滚动，关闭后焦点返回触发项。
- AC5：A/B 对比、关键页面冒烟、lint、test、build 全部通过。

## 7. 分类说明

本 PRD 仅覆盖新增用户能力。既有行为不符合预期的问题归类为 BUG，样式统一、字号、动效和布局调整归类为 Optimization，不在本 PRD 内重复定义。
